# Pro TDM Shooter: Scary Bird Assault

**Description:**  
Survive waves of attacking birds in a fast-paced TDM shooter with seasonal maps and realistic combat.

---

## Features

- Seasonal maps: Spring, Summer, Autumn, Winter  
- Birds attack randomly and face the player  
- Ammo system with reload functionality  
- High score tracking with “HURRAY!! NEW HIGH SCORE!!” message  
- Realistic player representation with Kar 98 gun  
- HUD showing Health, Ammo, Kills, and Time  

---

## Controls

- **W / A / S / D** → Move player  
- **SPACE** → Shoot bullets  
- **R** → Reload  
- **R (after game over)** → Restart game
